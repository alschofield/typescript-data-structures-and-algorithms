# Learning Repo Source Ownership

This is a learning repository. The user writes all production TypeScript by hand.

- Do not create, delete, or modify production implementation files under src/: .ts files other than *.test.ts.
- This includes blank scaffolds, declarations, stubs, and translations of README contracts into production code.
- Never rewrite, replace, or delete user-written production implementations.
- Tests, README files, and tooling are agent-editable when needed or requested.
- Review production source read-only: report findings, let the user make logic changes, then re-review and verify.
